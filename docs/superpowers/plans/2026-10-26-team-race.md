# Personale vs Spie implementation plan

**Goal:** Four personnel missions and three spy missions; first team completing all its missions wins, with the same result shown to everyone.
**Architecture:** BrowserRoom remains host-authoritative. An explicit race mode owns two progress ledgers and an immutable first winner. Solo campaign remains separate. Mission activities reuse the existing modal and map; progress helpers accept a mission catalog. No external game service.
**Approved spec:** User confirmed Personale vs Spie, all missions required, global victory screen. Existing night cartoon art, WebRTC LAN and GitHub Pages retained. Attached documents are design references; fictional activities do not reproduce nuclear assembly or detonation procedures. Facts and adaptations remain labeled.
